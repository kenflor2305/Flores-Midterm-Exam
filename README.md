# Coca-Cola — Open Happiness

**Live site:** https://kenflor2305.github.io/YOUR-REPO/

## About

This is a simple, responsive Coca-Cola concept website
featuring product photos, brand information, and a contact form.
It is designed for visitors who want to explore Coca-Cola
through a clean and modern website.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | #FFF8F0` | Main background |
| Secondary | 30% | #202020` | Text and dark sections |
| Accent | 10% | #E41D2D` | Buttons, links, highlights |

Dark mode uses #111111` as its main background.

### Visual style

**Style chosen:** Glassmorphism

**Why I chose it:** Rounded cards, subtle borders, and
simple layouts create a clean and modern appearance.

### Contrast check

Body text color vs. background color: #202020` on #FFF8F0`

Contrast ratio: approximately **15.6 : 1**
(Needs to be at least 4.5 : 1)

Tool used: WebAIM Contrast Checker

https://webaim.org/resources/contrastchecker/

Check other text and background combinations before
submitting the project.

## Features

- [x] Mobile-first responsive layout
- [x] Dark mode toggle
- [x] GSAP page-load intro animation
- [x] Scroll reveals using ScrollTrigger
- [x] Scroll progress bar using scrub
- [x] Reduced-motion support
- [x] Product photography
- [x] Contact form with required fields
- [x] Saved theme preference using localStorage

## Built With

HTML, Tailwind CSS CDN, JavaScript, GSAP 3.13.0,
and ScrollTrigger 3.13.0.

## Project Structure

- `index.html` — Website structure and styling
- `script.js` — Dark mode and animations
- `README.md` — Project documentation

## Run Locally

Open `index.html` in a browser.

An internet connection is required for the CDN libraries
and remote product photographs.

## GitHub Pages Deployment

1. Create a public GitHub repository.
2. Upload all three project files.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select `main` and `/(root)`.
6. Save and wait for deployment.
7. Replace the Live site URL above with your real URL.
